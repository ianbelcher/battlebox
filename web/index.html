BattleBox

One blocky world, always on. Build a fort — then defend it.

Needs a computer with a keyboard and mouse — phones and tablets can't play yet.

How it works

Everyone who joins is in the same world at the same time, building on each other's work. Break blocks, place blocks, open E for the whole block palette and the ready-made building kits. When the fort is ready, press Attack! in the top bar to call in a Grump raid — they can only step up one block, so a real wall really works.

The world is a sandpit, not a save file: it lives while the server is up and starts fresh when it restarts. Build big, knock it down, start again.

Sharing one computer? Press Space, Enter, or a gamepad's A button and a second, third or fourth player drops in — the screen splits itself.

Prefer to install it?

The browser version is the same game and the easy way in. An installed copy runs a little smoother on an older machine, and starts faster after the first time.

Windows .exe macOS .zip Linux x86-64
Opening the download on each system

Windows: SmartScreen will say it doesn't recognise the app, because the build isn't code-signed. Choose More info → Run anyway.

macOS: unzip it, then right-click the app → Open the first time; double-clicking a first-run unsigned app just refuses.

Linux: chmod +x battlebox-linux.x86_64 and run it. If nothing happens, run it from a terminal to see why, and try --rendering-method mobile or --rendering-driver opengl3.

Installed copies check for updates themselves — the menu offers to fetch a new build and restart into it.

Running slow?

In the game, press ` → Video. Turn the view distance and effects down, and try Renderer: Lite — the game restarts itself into a much lighter graphics mode. On a laptop, plugging it in often doubles the frame rate on its own.
