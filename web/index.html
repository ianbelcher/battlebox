Boxel

One cozy world, always on. Grab the game for your computer, open it, and press Connect — the address is already filled in. Up to four players per computer: press Space, Enter, or a gamepad's A button to hop in.

macOS Windows Linux

macOS: unzip, then right-click the app → Open the first time (it isn't signed). Linux: chmod +x it first.

Old computer running slow? In the game, open the menu (Esc) → Video tab: turn things off or down until it is smooth, and try "Renderer: Lite" — the game restarts itself into a much lighter graphics mode.

Controls (like Minecraft) — WASD + mouse, left-click break, right-click place, E for all blocks & building kits, R throws orbs, Esc for the guide. Double-tap jump to fly. Gamepad: stick + A, B break, X place, right trigger throws, D-pad up picks, Start for the guide. T / Y switches first person ↔ overview. Press ⚔ Attack! up top to start a Grump raid — build a fort first!

Linux: if it won't start, run it from a terminal to see why: ./boxel-linux.x86_64, and try --rendering-method mobile or --rendering-driver opengl3; send us the output.
