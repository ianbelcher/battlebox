Belcher World

One cozy world, always on. Grab the game for your computer, open it, and press Connect — the address is already filled in. Up to four players per computer: press Space, Enter, or a gamepad's A button to hop in.

macOS Windows Linux

macOS: unzip, then right-click the app → Open the first time (it isn't signed). Linux: chmod +x it first.

Controls — keyboard 1: WASD + Space, E dig, F place, Tab cycle blocks. Keyboard 2: arrows + Enter, . dig, , place. Gamepad: stick + A jump, B dig, X place, bumpers cycle. Hold Q / Backspace / Back to leave.

Server: ws://10.0.0.200:30810 · runs on the cluster · the world is saved, so whatever you build is still there tomorrow.
